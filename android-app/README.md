# أحمد سبورت – Ahmed Sport

هذا المجلد هو مشروع Android Studio أصلي مستقل باسم الحزمة `com.ahmedsport.app`. التطبيق مكتوب بـ Kotlin، ويعرض واجهة HTML/CSS محلية داخل WebView، ثم يفتح `PlayerActivity` الأصلي عند الضغط على زر «قناة أحمد سبورت 1». المشغل مبني على AndroidX Media3 ExoPlayer ويدعم HLS/M3U8، الإيقاف المؤقت، زر كتم/تشغيل الصوت، شريط التحميل، ملء الشاشة، التبديل بين مصادر القناة، وإعادة المحاولة.

## إعداد روابط البث

روابط البث لا تُكتب داخل Kotlin أو HTML. المكان الوحيد لتعديلها هو الملف المحلي:

```text
android-app/stream-urls.properties
```

هذا الملف غير متعقب في Git لأن الروابط المرسلة تحتوي على بيانات وصول يمكن اعتبارها حساسة. يوجد ملف آمن كنموذج باسم `stream-urls.properties.example`. عند نسخ المشروع إلى جهاز آخر، انسخ النموذج إلى `stream-urls.properties` وأضف روابط HLS المصرح بها بالترتيب التالي:

```properties
AHMED_STREAM_1=ضع_الرابط_الأول_هنا
AHMED_STREAM_2=ضع_الرابط_الثاني_هنا
AHMED_STREAM_3=ضع_الرابط_الثالث_هنا
AHMED_STREAM_4=ضع_الرابط_الرابع_هنا
```

يتم تحويل القيم أثناء البناء إلى `BuildConfig`، ثم يقرأها `StreamConfig.kt`. لا تضف روابط قنوات جديدة؛ القيم الأربع هي مصادر بديلة للقناة الوحيدة نفسها. لا تنشر ملف `stream-urls.properties` أو تعيد استخدام الروابط إلا إذا كان لديك تصريح من مالك القناة أو مزود الخدمة.

## البناء من Android Studio

1. افتح Android Studio واختر **Open** ثم حدّد مجلد `android-app`، وليس مجلد Expo الموجود في الجذر.
2. ثبّت Android SDK Platform 35 وBuild Tools المتوافقة، واستخدم JDK 17. سيستخدم المشروع Android Gradle Plugin 8.7.3 وGradle 8.9.
3. أنشئ `stream-urls.properties` من النموذج، أو استخدم الملف المحلي الموجود لديك، ثم نفّذ **Sync Project with Gradle Files**.
4. اختر جهازاً فعلياً أو محاكي Android واضغط **Run**. للبناء التجريبي اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. ستجد الملف عادة في `app/build/outputs/apk/debug/app-debug.apk`. وللإصدار النهائي استخدم **Build > Generate Signed Bundle / APK** وأنشئ مفتاح توقيع خاصاً بك.

أو بعد توفر Android SDK وGradle Wrapper على جهازك:

```bash
cd android-app
./gradlew assembleDebug
```

## مسار التشغيل

تبدأ `MainActivity` بتحميل `file:///android_asset/web/index.html` داخل WebView. جسر JavaScript باسم `AhmedSport` يستقبل نقرة زر القناة ويشغّل `PlayerActivity`. عند بدء المشغل تظهر شاشة تحميل. إذا فشل مصدر HLS، ينتقل التطبيق تلقائياً إلى المصدر التالي من القائمة نفسها. بعد فشل آخر مصدر تظهر رسالة عربية واضحة وزر «إعادة المحاولة» يعيد الاختبار من المصدر الأول. عند العودة من الخلفية تُعاد تهيئة جلسة ExoPlayer تلقائياً.

تم تفعيل صلاحية الإنترنت و`ACCESS_NETWORK_STATE`. وبما أن الروابط الحالية تستخدم HTTP، أضيف إعداد Network Security Config مقيد بنطاق `kingtv.net`. يفضّل استخدام روابط HTTPS عند توفرها لدى مزود الخدمة.

## اختبار القبول

للتأكد من التشغيل الطبيعي، شغّل التطبيق واضغط زر القناة وتحقق من ظهور المشغل وعناصر التحكم ثم جرّب الإيقاف المؤقت، كتم/تشغيل الصوت، شريط التحميل، وملء الشاشة. لاختبار فشل الشبكة، عطّل الإنترنت أثناء التحميل أو ضع رابطاً غير صالح مؤقتاً في `stream-urls.properties`: يجب أن تظهر حالة التحميل، ثم تجربة المصادر البديلة، ثم رسالة الخطأ وزر إعادة المحاولة. بعد إعادة الإنترنت وإرجاع الرابط الصحيح يجب أن يعاود الزر التشغيل.

بيئة Manus الحالية لا تحتوي على Android SDK أو Gradle قابل للتنفيذ، لذلك تم إجراء تحقق ثابت لبنية المشروع، مسارات الموارد، ملفات Gradle، Manifest، وكود Kotlin. يلزم تنفيذ البناء الفعلي على جهاز Android Studio أو بيئة CI تحتوي على Android SDK.
