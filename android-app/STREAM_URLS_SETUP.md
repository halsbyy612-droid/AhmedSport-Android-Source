# إعداد روابط القناة

ملف `stream-urls.properties` هو ملف محلي واحد لتعديل مصادر قناة أحمد سبورت 1. انسخ `stream-urls.properties.example` إلى `stream-urls.properties` ثم ضع الروابط المصرح بها.

لا تضع هذه القيم داخل `MainActivity.kt` أو `StreamConfig.kt` أو HTML/CSS. لا ترفع الملف إلى Git أو ترسله في حزمة عامة؛ قد تتضمن الروابط بيانات اعتماد للوصول إلى مزود البث.
